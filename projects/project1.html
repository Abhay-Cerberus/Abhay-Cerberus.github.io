Travel Agent

Overview

An intelligent travel itinerary planner powered by LLMs (via Pydantic-AI), Amadeus APIs, Eventbrite APIs, and OpenStreetMap.

Technologies Used

Python Pydantic-AI APIs OpenStreetMap

Description

  • Validated request schemas using Pydantic-AI for robustness
  • Integrated Amadeus API to suggest live flight options
  • Recommended local experiences via Eventbrite API
  • Queried OpenStreetMap Overpass API for dining and sightseeing
  • Resolved IATA codes from raw city input automatically
  • Added error handling and retry logic to ensure reliability
