AI Image Generator

Overview

A modular scraping tool for Steam game insights, enriching raw data with metrics and storing outputs in reusable formats.

Technologies Used

Python Requests BeautifulSoup APIs

Description

  • Scraped game data using Requests and BeautifulSoup
  • Enriched datasets with analytics via Gamalytics API
  • Stored results in CSV and JSON formats
  • Implemented deduplication and managed rate limits
  • Packaged as a developer-friendly module with documentation
