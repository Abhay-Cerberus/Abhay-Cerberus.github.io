Kalyan ML

Overview

Predicting mood from a 1,000-record synthetic wellness dataset using Python and a Random Forest model.

Technologies Used

Python NumPy Pandas Scikit-learn Matplotlib Seaborn

Description

  • Generated a synthetic dataset of 1,000 records covering steps, sleep, mood, diet, stress, screen time, and social hours.
  • Visualized key relationships with a social hours vs. mood scatterplot.
  • Explored feature interdependencies using a correlation heatmap.
  • Trained a Random Forest regressor yielding RMSE 0.33 and R² 0.78 on mood prediction.
  • Highlighted social hours and sleep duration as top mood drivers via feature importance.
