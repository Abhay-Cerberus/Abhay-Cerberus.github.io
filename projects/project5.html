Overview

A script that scrapes the current game prices from gg.deals by converting game names into URL-compatible formats and extracting price data from official stores and keyshops.

Technologies Used

Python Requests BeautifulSoup RegEx

Description

  • Uses requests and BeautifulSoup to fetch and parse HTML from a game's gg.deals page.
  • Transforms game titles (e.g., replacing spaces, colons, and periods) for valid URL endpoints.
  • Locates a key HTML block (header-game-prices-content active) to extract price text.
  • Applies regex parsing to capture labeled prices for "official stores" and "keyshops".
  • Returns structured price data or "Free" if no values are found.
