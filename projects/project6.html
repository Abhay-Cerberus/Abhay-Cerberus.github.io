Task Management System

Overview

Note-Keeper extension lets users download text notes as .txt files with customizable names and instant creation.

Technologies Used

HTML JavaScript

Description

  • Captures user input from Name and Content fields.
  • Generates a plain-text blob and creates a dynamic download link.
  • Uses Current time for timestamp uniqueness when needed.
  • Supports fallback defaults for empty fields (output.txt, blank content).
